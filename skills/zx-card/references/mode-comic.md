# 漫画模式 (-c)

日式黑白漫画风格，动态选择漫画家视觉语言。

## 执行步骤

### 1. 分析内容叙事

判断内容适合哪种漫画语言：

| 叙事特征          | 漫画家参考           | 视觉语言             |
| ----------------- | -------------------- | -------------------- |
| 内心独白/意识流   | 手冢治虫             | 变形、象征、跨页大画 |
| 现实主义/社会问题 | 浦泽直树             | 写实线条、电影感分镜 |
| 青春/情感         | 新海诚（动画转漫画） | 细腻背景、光影氛围   |
| 动作/张力         | 井上雄彦             | 速度线、留白、冲击力 |
| 日常/温暖         | 宫崎骏（动画转漫画） | 柔和线条、自然元素   |

### 2. 设计分镜

- 每格一个信息单元
- 格与格之间用 gutter（间距）区分
- 阅读顺序：左上到右下（日式）或左到右（美式）

### 3. 视觉元素

- 线条：黑色粗轮廓，内部细节用细线
- 网点：灰度用网点表现
- 速度线：动作和张力
- 拟声词：手写风格
- 留白：重要，制造节奏

模板文件：`assets/comic_template.html`
