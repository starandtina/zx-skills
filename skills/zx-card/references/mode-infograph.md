# 信息图模式 (-i)

内容驱动的自适应视觉布局，1080px 宽度。

## 执行步骤

### 1. 提取核心信息

- 找出内容中的关键数据、对比、流程、关系
- 识别可以用视觉元素表达的信息

### 2. 选择视觉形式

根据内容选择最适合的形式：

| 内容特征    | 视觉形式            |
| ----------- | ------------------- |
| 时间线/演进 | 横向或纵向时间轴    |
| 对比/选择   | 左右分栏或 2x2 矩阵 |
| 流程/步骤   | 箭头连接的流程图    |
| 层级关系    | 树状图或金字塔      |
| 数据分布    | 简单的条形图或点阵  |
| 概念关联    | 网络图或思维导图    |

### 3. 设计原则

- 信息密度：一屏一个核心洞察
- 视觉层次：大小、颜色、位置区分重要性
- 对齐：有意的错落，不是随意的混乱
- 图标：简单几何形状，不用复杂图标库

### 4. 填充模板

模板文件：`assets/infograph_template.html`

### 5. 截图

```bash
node assets/capture.js <html_path> <png_path> 1080 <height> fullpage
```

### 6. 交付

报告文件路径。
