# 白板模式 (-w)

白板马克笔风格，结构化框图+箭头+彩色标记。

## 执行步骤

### 1. 提取结构

识别内容中的：

- 核心概念（方框）
- 关系（箭头）
- 分组（区域）
- 强调（颜色标记）

### 2. 布局设计

- 中心放核心概念
- 相关概念围绕中心
- 用箭头表示流向或关系
- 用颜色区分不同类型

### 3. 白板风格

- 背景：轻微纹理，像真实白板
- 框：手绘矩形，不完全闭合
- 箭头：手绘风格，有箭头头
- 文字：手写体或粗体无衬线
- 标记：荧光笔效果的高亮

### 4. 填充模板

模板文件：`assets/whiteboard_template.html`

### 5. 截图

```bash
node assets/capture.js <html_path> <png_path> 1080 <height> fullpage
```
