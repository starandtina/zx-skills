# 品味准则

**所有模具共享。** 执行任何模具前，先阅读本文件，作为视觉质量底线贯穿全流程。

核心原则：**反 AI 生成痕迹**。

## 禁止

| 禁止项     | 说明                                                           |
| ---------- | -------------------------------------------------------------- |
| Inter 字体 | 不用任何 Inter 变体。正文用 Noto Serif SC，标题用 Noto Sans SC |
| 纯黑       | 背景 `#1a1a1a`，文字 `#e8e8e8`，不用 `#000` 和 `#fff`          |
| 三等分卡片 | 不用「问题-解法-结果」三段式布局                               |
| 居中 Hero  | 不用大标题居中 + 下面堆内容                                    |
| AI 文案腔  | 不用「值得注意的是」「这启示我们」「我们可以得出」等           |
| 假数据     | 不用「约 70%」「研究表明」等模糊数字，要么给具体数字，要么不说 |

## 推荐

| 推荐项   | 说明                                               |
| -------- | -------------------------------------------------- |
| 衬线体   | 中文正文用 Noto Serif SC，英文用 Georgia/Times     |
| 微暖背景 | 深色模式用暖黑 `#1a1a1a`，浅色模式用暖白 `#f8f6f3` |
| 错落布局 | 元素不对称分布，有呼吸感                           |
| 手写感   | 标题可用手写体（如 ZCOOL XiaoWei）增加人文气息     |
| 留白     | 边缘留白 60px 以上，元素之间间距充足               |
| 具体     | 用具体名词和动词，不用抽象形容词                   |

## 色彩

- 深色背景：`#1a1a1a`
- 浅色背景：`#f8f6f3`
- 文字主色：`#e8e8e8`（深色背景）或 `#2d2d2d`（浅色背景）
- 强调色：根据内容选择，如琥珀 `#f5a623`、青绿 `#4ecdc4`、珊瑚 `#ff6b6b`
- 渐变：从强调色到背景色的柔和渐变，不突兀

## 排版

- 行高：1.6-1.8
- 字间距：中文 0.05em，英文 normal
- 段落间距：1.5 倍行高
- 引用：左侧 3px 强调色边框，内边距 20px
