# 模具：大字（-b）

## 核心信条

一句话砸在纸上。字要大，纸要旧，整张图像一页被揭下来的附件。

`-b` 只服务单句或短段。它不负责解释复杂结构，只负责让一个判断有重量。

## 适用内容

- 一句观点或判断：15-30 字
- 一个反问：10-25 字
- 一条标语：8-25 字
- 最多两句，总长 30-60 字

超过 60 字时，提醒用户换 `-l` 长图或 `-m` 多卡。不要为了塞进去而把字号压小。

## 字号

按字符数估算 `{{FONT_SIZE}}`，再根据实际断行上下浮动 10-15%：

| 字符数 | 字号 | 每行参考 |
| ------ | ---- | -------- |
| <= 10  | 220  | 3-4 字   |
| 11-16  | 190  | 4-5 字   |
| 17-24  | 160  | 5-6 字   |
| 25-34  | 135  | 6-7 字   |
| 35-46  | 115  | 7-9 字   |
| 47-60  | 98   | 8-10 字  |

## 手动断行

不要依赖浏览器自动换行。把 `{{MAIN_TEXT}}` 写成带 `<br>` 的语义断行：

```html
第一行<br>
第二行<br>
<span class="shu">关键词</span>第三行<br>
第四行
```

断行原则：

- 按语义单元切，不在词中切
- 每行字数相近，差异尽量不超过 2 字
- 标点跟着前一句，不单独起行
- 反问词、转折词、核心名词可以起新行
- 每张图最多一处 `.shu` 朱砂高亮

## 模板变量

读取 `assets/big_template.html` 并替换：

- `{{FONT_SIZE}}`：字号数值，不带 `px`
- `{{MAIN_TEXT}}`：主文 HTML，允许 `<br>` 与 `<span class="shu">`
- `{{SOURCE_LINE}}`：来源线 HTML 或空字符串
- `{{LOGO}}`：logo 图片路径，通常为 `assets/logo.png`
- `{{CUSTOM_CSS}}`：可选微调 CSS，无需则留空

## 截图

在 skill 根目录写临时 HTML 到 `/tmp/zx_cast_big_{name}.html`，输出到 `~/Downloads/{name}.png`。

```bash
node assets/capture.js /tmp/zx_cast_big_{name}.html ~/Downloads/{name}.png 1080 1440
```

## 验收

- 一眼能读完，不需要扫读
- 主文字号足够大，每行像一块石刻
- 纸张纹理不抢字，旧感来自噪声和墨迹边缘，不是脏滤镜
- 签名和来源不干扰主文
- 1080 x 1440 固定尺寸，没有滚动长图
