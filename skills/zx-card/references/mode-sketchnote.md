# 视觉笔记模式 (-v)

手绘风格 sketchnote，动态选择风格路线。

## 执行步骤

### 1. 分析内容气质

判断内容适合哪种视觉路线：

| 气质      | 路线     | 特征                     |
| --------- | -------- | ------------------------ |
| 理性/分析 | 架构路线 | 框图、箭头、层级         |
| 感性/叙事 | 流动路线 | 曲线、有机形状、手绘感   |
| 对比/辩论 | 张力路线 | 左右分栏、对比色、冲突感 |
| 探索/发现 | 地图路线 | 路径、地标、旅程感       |

### 2. 提取视觉元素

- 核心概念 → 图标或符号
- 关系 → 箭头或连接线
- 层次 → 框或区域
- 强调 → 颜色或大小

### 3. 手绘风格

- 线条：略带抖动，不完美
- 形状：圆角、有机边缘
- 字体：手写体或衬线体
- 颜色：有限调色板（2-3 色）

### 4. 填充模板

模板文件：`assets/sketchnote_template.html`

### 5. 截图

```bash
node ~/.claude/skills/zx-card/assets/capture.js <html_path> <png_path> 1080 <height> true
```

报告文件路径。
