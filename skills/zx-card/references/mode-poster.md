# 多卡模式 (-m)

自动切分为多张阅读卡片，每张 1080x1440px。

## 执行步骤

### 1. 内容分块

将长内容切分为逻辑独立的块：

- 每块一个核心观点
- 每块 200-400 字
- 块之间有自然的过渡

### 2. 设计每张卡片

每张卡片结构：

- 顶部：卡片序号（如 1/5）
- 中间：核心内容
- 底部：footer（可选来源）

### 3. 生成多张 HTML

为每张卡片生成独立的 HTML 文件。

### 4. 批量截图

```bash
# 对每张卡片
node assets/capture.js <html_path> <png_path> 1080 1440
```

### 5. 交付

报告所有 PNG 文件路径。
