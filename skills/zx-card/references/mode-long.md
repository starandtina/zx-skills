# 长图模式 (-l)

单张阅读卡片，1080px 宽度，高度自适应内容。

## 执行步骤

### 1. 分析内容

- 提取核心观点、关键论据、结论
- 识别内容类型：概念解释、方法论、观点论述、故事叙述

### 2. 设计结构

根据内容类型选择结构：

| 类型     | 结构                                    |
| -------- | --------------------------------------- |
| 概念解释 | 定义 → 核心特征 → 例子 → 边界           |
| 方法论   | 问题 → 核心思路 → 步骤 → 检验标准       |
| 观点论述 | 反直觉判断 → 支撑论据 → 反驳处理 → 结论 |
| 故事叙述 | 场景 → 冲突 → 转折 → 启示               |

### 3. 视觉设计

- 背景：深色 `#1a1a1a` 或浅色 `#f8f6f3`
- 字体：Noto Serif SC（正文）+ Noto Sans SC（标题）
- 标题：24-32px，手写体可选
- 正文：16-18px
- 强调：强调色高亮关键词
- 引用：左侧边框 + 斜体

### 4. 填充模板

模板文件：`assets/long_template.html`

替换变量：

- `{{TITLE}}`：卡片标题
- `{{CONTENT}}`：HTML 格式的内容
- `{{SOURCE_LINE}}`：来源信息（可选）

### 5. 截图

```bash
node ~/.claude/skills/zx-card/assets/capture.js <html_path> <png_path> 1080 <height> true
```

`true` 表示 fullpage，自动计算高度。
