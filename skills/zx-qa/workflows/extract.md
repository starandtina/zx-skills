# Extract Workflow

## 1. 先写骨架，不写问答

通读后先写内部骨架：

```text
作者要证明：
  ...
推理台阶：
  1. ...
  2. ...
  3. ...
最大边界：
  ...
```

骨架没站住时不要开始生成 Q。

## 2. 把台阶改成问题

每个推理台阶只生成一个承重问题。一个问题必须让后一个问题自然冒出来。

如果两个问题可以交换顺序而不影响理解，说明它们只是并列知识点，需要重排或删除。

## 3. 答案四段

每个答案严格四段：

```text
结论：
一句话回答问题。

形式化：
用一行关系压缩思想。

论证步骤：
2-4 句说明怎么从前提走到结论。

边界：
说明什么条件下不成立。
```

## 4. 删除测试

生成后逐个删除 Q：

- 删除后主线不断 -> 这个 Q 是装饰，删掉
- 删除后后文失去前提 -> 保留
- 删除后只是少了一个例子 -> 合并到相邻答案

最终保留 5-9 个问题。短文可以 3-5 个，长书可以 9-12 个，但每个都要承重。
