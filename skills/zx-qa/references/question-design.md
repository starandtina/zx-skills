# Question Design

好问题不是把标题改成问号。好问题是把作者推理链里最承重的关节暴露出来。

## 问题类型

- 缺口题：如果旧方法已经够用，为什么还需要这篇文章？
- 转向题：作者把注意力从哪里挪到了哪里？
- 机制题：哪一个动作让结果改变？
- 代价题：这个解法省下了什么，又把成本转移到哪里？
- 边界题：在什么条件下，作者的判断会失效？
- 反事实题：如果拿掉一个前提，结论会怎样变？

## 坏问题

- 定义题：「什么是 X？」
- 目录题：「作者讲了哪些方面？」
- 复述题：「这篇文章的主要观点是什么？」
- 安慰题：「这个方法有什么优势？」
- 空泛题：「这给我们什么启发？」

坏问题不是永远不能出现，而是不能占据 Q-A 链的承重位置。定义只能作为答案中的工具，不当成问题本身。

## 磨尖方法

把弱问题连续追问三次：

1. 它为什么重要？
2. 它和相邻做法差在哪里？
3. 它什么时候不成立？

例子：

- 弱：什么是奖励模型？
- 中：奖励模型为什么会影响生成路径？
- 强：为什么只奖励最终正确，可能会训练出一条错误但偶然到达答案的路径？

## 排序

按依赖关系排，不按原文目录排：

```text
困境 -> 旧路为什么不行 -> 作者的新看法 -> 机制如何工作 -> 证据支持到哪 -> 边界在哪里 -> 读者该怎么判断
```
